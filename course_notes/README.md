# Course Notes

This folder will contain polished module notes generated from:

- raw lesson markdown in `course_source/`
- git commit history
- the current implementation in this repo

The intended output is one markdown file per module:

```text
module-01-preprocessing.md
module-02-tf-idf.md
module-03-keyword-search.md
module-04-semantic-search.md
module-05-chunking.md
module-06-hybrid-search.md
module-07-llms.md
module-08-reranking.md
module-09-evaluation.md
module-10-augmented-generation.md
module-11-agentic.md
```

Each note should explain what was implemented, how the system flows, the underlying concepts, design tradeoffs, and useful CLI commands.
